🗄️ Supabase Database NOT SET
Connect a free Supabase database so all technicians' logs go to one place.

Setup steps:
1. Go to supabase.com → New project (free)
2. Go to SQL Editor → paste and run the setup SQL below
3. Go to Settings → API → copy Project URL and anon key
4. Paste both below and tap Save
CREATE TABLE caltrack_logs ( id bigserial primary key, batch_id text, mode text, technician text, site text, timestamp timestamptz, instr_id text, model text, make text, serial text, cal_due text, is_master boolean, pass_fail text, reading text, unit text, note text ); ALTER TABLE caltrack_logs ENABLE ROW LEVEL SECURITY; CREATE POLICY "allow all" ON caltrack_logs FOR ALL USING (true) WITH CHECK (true);
